| Capacidad                                   | Clasificación         | Valor                                                                                    |
| ------------------------------------------- | --------------------- | ---------------------------------------------------------------------------------------- |
| Registrar nuevas tareas                     | **Esencial para MVP** | Permite al equipo incorporar tareas al sistema y comenzar su seguimiento.                |
| Visualizar las tareas registradas           | **Esencial para MVP** | Permite conocer de forma clara qué tareas existen y consultar su información.            |
| Actualizar el estado de una tarea           | **Esencial para MVP** | Permite reflejar el avance real de cada tarea conforme cambia su situación.              |
| Identificar tareas pendientes y completadas | **Esencial para MVP** | Facilita distinguir rápidamente qué trabajo falta y qué trabajo ya terminó.              |
| Editar la información de una tarea          | **Posterior**         | Permite corregir o ajustar datos de una tarea después de haberla registrado.             |
| Eliminar tareas                             | **Posterior**         | Permite retirar tareas que ya no sean necesarias o que hayan sido registradas por error. |
| Filtrar o buscar tareas                     | **Posterior**         | Facilita localizar tareas específicas cuando aumente la cantidad de registros.           |
| Ordenar o agrupar tareas                    | **Posterior**         | Permite organizar visualmente el trabajo para facilitar su consulta y seguimiento.       |
